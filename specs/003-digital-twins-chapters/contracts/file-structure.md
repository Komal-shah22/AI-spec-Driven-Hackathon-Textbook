# Contract: File and Folder Structure

This document defines the file and folder structure conventions for the "Digital Twins, Simulation, and Sensors" module.

## Directory Structure

The new chapters will be located under the `docs/module-2/` directory. The proposed structure is as follows:

```
docs/
└── module-2/
    ├── 01-intro-to-digital-twins.md
    ├── 02-simulation-environments.md
    ├── 03-building-a-robot-model.md
    └── 04-integrating-sensors.md
```

## Naming Conventions

-   **Files**: Markdown files should be named with a two-digit prefix to enforce order, followed by a short, descriptive name in kebab-case (e.g., `01-intro-to-digital-twins.md`).
-   **Static Assets**: Images and other static assets related to this module should be stored in `static/img/module-2/` and named descriptively.
