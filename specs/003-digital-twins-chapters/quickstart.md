# Quickstart

This guide provides instructions on how to build and view the documentation locally.

## Prerequisites

-   Node.js and npm installed.

## Instructions

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Run the Development Server**:
    ```bash
    npm start
    ```

3.  **View the Documentation**:
    Open your web browser and navigate to `http://localhost:3000`. You should see the documentation website, including the new chapters under Module 2.
